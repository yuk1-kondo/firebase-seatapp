# Event Runbook

## URLs

- Seat list: `https://seat-app-f68f7.web.app/index.html`
- Roulette: `https://seat-app-f68f7.web.app/control.html?admin=true`
- Admin: `https://seat-app-f68f7.web.app/admin.html`

## Devices

- Tablet: use the roulette screen
- Mac + projector: show the seat list
- Admin smartphone: open the admin screen
- Participants: check the seat list on their phones

## Before the event

1. Open `admin.html` on the admin smartphone.
2. Enter the admin PIN code that was shared with organizers.
3. Confirm the event title, members, tables, and fixed seats.
4. Save the settings and verify they are reflected.
5. Open the seat list on the Mac and confirm it is readable on the projector.
6. Open the roulette page on the tablet and confirm organizer access works.
7. Run one or two test assignments, then reset assignments if needed.

## During the event

1. On the tablet, select a participant on the roulette page.
2. Start the roulette and stop it to assign a seat.
3. Confirm the result appears on the projector seat list.
4. Ask participants to check the seat list on their phones if needed.

## If something goes wrong

- If the seat list looks stale, reload `index.html`.
- If organizer controls are hidden, reopen the page and enter the PIN again.
- If a wrong assignment was made, use the reset button from organizer mode.
- If settings were updated on the admin phone, reload the roulette and seat list pages to pick up the latest settings.

## Notes

- This app is intended for single-operator event use.
- Avoid running the roulette from multiple devices at the same time.
- Share the admin PIN only with organizers.
