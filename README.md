# firebase-seatapp

リアルタイムで座席の割り当てを確認・更新できる Firebase Hosting アプリです。2025 年度の桜和会イベント向けに作成された座席表と管理ツールを含みます。

## 主な画面

- `index.html` : 座席一覧をリアルタイム表示。テーブルは 4 列グリッドで伸縮し、最大 10 席まで表示できます。
- `control.html` : 参加者を選んでルーレット形式で席を割り当てる管理画面。

## 最近のアップデート

- レイアウト全体をビューポートサイズに合わせてスケールするよう改善
- テーブル数・席数の増減に強い 4 列グリッドへ刷新
- 各画面のカラーパレットを統一し、ダークブルー × オレンジのテーマに調整

## デプロイ

```bash
firebase deploy --only hosting
```

プレビュー用には `firebase hosting:channel:deploy <channel-name>` を使用します。
